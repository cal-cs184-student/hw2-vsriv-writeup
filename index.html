These are calculated using the parameter t based on the equation: \[ p_{i}^{'} = t * p_i + (1-t) * p_{i+1} \] where \( p_{i}^{'} \) is the intermediate control point on the next step/level. This is evaluated recursively until a single point is found (shown in red). When calculated across various values of t between 0 and 1, we get the Bezier curve (shown in green).

Next, the new vertex is created at the midpoint of the split edge, and the necessary half edges are created as well.
